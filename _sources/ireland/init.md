# init.md — chapter chat bootstrap (Irish history)

To start a chapter working session, fetch these three files in order and
treat them as the authoritative context for everything that follows. Then
give me a one-line confirmation of each (title + draft version) before we
begin, so I can see the fetch succeeded and we're on the current versions.

1. Canon (spine — periodization, 11-chapter map, five paradoxes,
   revisionism stance, glossary):
   https://raw.githubusercontent.com/johsieders/essays/main/bagatelles/ireland/canon.md

2. Style guide (how the prose should read):
   https://raw.githubusercontent.com/johsieders/essays/main/bagatelles/style.md

3. The chapter in play — replace N with the chapter number:
   https://raw.githubusercontent.com/johsieders/essays/main/bagatelles/ireland/ireland-N.md

If any fetch fails, say so and stop — do not proceed on a stale or
missing file.
